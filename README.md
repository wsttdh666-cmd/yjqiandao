# 一键签到

一个安卓 App：把你常用的 API 中转站放在一起，一键全部签到，顺便看余额、模型价格、调用日志。

---

## 一、数据安全（先看这里）

- **所有数据只存在你自己的手机里。** 这个 App 没有服务器，开发者也收不到你的任何东西。
- 存的东西包括：站点网址、账号密码、密钥、登录状态。这些都用手机系统自带的安全芯片（Android Keystore）加密保存，别的 App 读不到。
- App 联网时，只会直接连这几个地方：
  - 你自己添加的站点；
  - GitHub，用来检查更新；
  - 用「官方转接」时，连 OpenAI。
- 导出的备份文件，用你自己设的密码加密。密码别设太简单；忘了密码，文件就打不开了。
- **卸载 App 会清空所有数据。** 换手机或卸载前，先用「导出站点」做个备份。
- **安装包只从本仓库的 [Releases](https://github.com/wsttdh666-cmd/yjqiandao/releases) 下载，或在 App 里点「检查更新」。** 别装别人转发的安装包，那可能被人改过，会偷你的账号。

## 三、安装和更新

1. 到 [Releases](https://github.com/wsttdh666-cmd/yjqiandao/releases) 下载最新的 `.apk`，点开安装。
2. 以后更新：点 App 右上角的「检查更新」，有新版会直接下载安装，不用卸载旧版。

## 四、添加站点

1. 点右上角的 **＋**。
2. 填 **网址**，App 会自己认出这是什么站，不用你选类型。
3. 选 **类型**：
   - **签到**：每天要签到的站，会参与「全部签到」。
   - **仅查看**：只看余额、模型、日志，不签到。
4. 登录方式二选一：
   - 填 **账号、密码**；
   - 点 **「在 App 里登录」**，在弹出的网页里自己登录（Discord 登录的站用这个，见第七节）。
5. 选填的几项：
   - **密钥**：只有密钥、没有账号的站，填这个也能查余额、看模型和日志。
   - **调用地址**：只有接口地址和网址不一样时才填。比如网址是网页地址，调用地址是 `https://api.xxx.com/v1`。空着就自动用「网址 + /v1」。
   - **备用网址**、**模型监控网址**、**模型价格网址**：站点提供才填。
6. 点 **保存**。

## 五、签到

- **全部签到**：点主页最上面的大按钮，所有「签到」类型的站一起签。
- **只签一个**：卡片上显示「未签」或「出错」的，直接点那个状态，就只签这一个站。
- **验证码 / 签到码**：有的站要填验证码，签到时会弹出填码框，每个框都写着是哪个站的。看不清可以点图片换一张。
- 签完卡片上会显示「余额 · 今日 +多少」。

## 六、余额、模型、日志、密钥

- **点卡片**：看网址、调用地址、密钥、邀请码，都能一键复制。
- **「模型」按钮**：
  - **模型**：看模型列表和价格，可以按「按次 / 按量 / 收藏」和厂商筛选；填了模型监控网址的，还会显示成功率。
  - **日志**：看最近的调用记录，可以按「全部 / 成功 / 失败」筛选。有的站本身不提供日志，会直接写明。

## 七、充值、Discord 登录、登录多久过期

- **充值**：点卡片上的「充值」会用手机浏览器打开充值页。**先在浏览器里登录一次这个站，再点充值就行了。**
- **Discord 登录的站**：添加站点时点「在 App 里登录」，**先在弹出的页面里登录一遍 Discord**，再用 Discord 登录这个站，登好了点上面的「登录好了，完成」。
- **登录多久过期**：
  - **填了账号密码的**：过期了 App 会自动重新登录，不用管。
  - **在 App 里登录的（包括 Discord）**：App 会保存登录状态 **30 天**，但站点自己可能更早让你下线。卡片上出现 **「去登录」**，点一下重新登录就好。

## 八、备份和换手机

- **导出站点**：在主页最下面。导出时设一个密码，得到一个备份文件。
- **导入站点**：在新手机上点「导入站点」，选备份文件，输入密码。已经有的站不会被覆盖。

## 九、官方转接（GPT）

把你的 **ChatGPT 付费号（Plus / Pro）** 额度，变成一个只有这台手机能用的接口地址，给酒馆用。走的是 OpenAI 给第三方应用的官方登录。**免费号用不了**，这是 OpenAI 的规定。

**开启**
1. 主页最下面点 **「官方转接」** → **开启**。
2. 读一下风险说明，勾选后点开启。
3. 手机问能不能发通知、能不能后台运行，都点 **允许**。转接在后台跑时，通知栏会一直有一条提示，这样才不会被系统关掉。

**登录 GPT**
1. GPT 那一行点 **「登录」**，会跳到浏览器。
2. 用你的 ChatGPT 付费号登录 → 点 **Continue** → 点同意。
3. 看到「回到一键签到看结果」后，切回 App，GPT 那一行会显示你的邮箱。

**在酒馆里用**
1. 在转接面板里复制 **调用地址**（`http://127.0.0.1:8317/v1`）和 **密钥**（`sk-local-` 开头）。
2. 酒馆里接口选 **Chat Completion → 自定义（OpenAI 兼容）**，把地址和密钥填进去。
3. 模型选 `gpt-` 开头的。

**几个设置**
- **并发**：同时最多跑几条请求，默认 2 个。
- **间隔**：两次请求之间至少隔几秒，默认 3 秒。
- **每日上限**：每个号一天最多用几次，默认 50 次；到了会提示，第二天自动恢复。
- 遇到限流，转接会自动停一会儿，不会一直重试。

**注意**
- 酒馆必须跟一键签到在**同一台手机**上。这个地址只有本机能连，别人连不上。
- 用量太大或分享给别人，账号仍可能被限制，后果自己承担。
- 想断开：在 App 里点「退出」，或去 ChatGPT 设置里把 QiandaoHub 的连接删掉。
